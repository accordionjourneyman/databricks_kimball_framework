# Phase 2.0 local SQL/Delta feasibility dossier — 2026-07-23

## Gate outcome

**QUALIFIED.** An original disqualification was superseded after primary-source
review. The failed run used Delta's unsuffixed `delta-spark_2.13:4.2.0`
artifact. Delta's 4.2.0 release notes state that this compatibility coordinate
targets Spark 4.1, while Spark 4.0.1 requires
`delta-spark_4.0_2.13:4.2.0`. The failure therefore did not disqualify Thrift;
it proved the Maven coordinate was wrong. A user-authorized, evidence-based
pin correction reopened the gate. The corrected clean run passed every gate
condition.

## Attempt 1

Commands:

```bash
docker compose -f phase2/harness/docker-compose.yml up -d --build
docker compose -f phase2/harness/docker-compose.yml exec -T dbt \
  dbt debug --profiles-dir .
```

Result: failed before connection. The dbt HTTP method required the adapter's
`PyHive` extra, and `dbt debug` reported that `git` was absent.

Single allowed remediation: install `git` and `dbt-spark[PyHive]` in the dbt
client image. This changes no Spark, Delta, metastore, model, or framework code.

## Attempt 2

The remediated dbt profile and project validated, and `git` was available.
The Spark Thrift process then terminated before its endpoint became healthy.
The retained server log ends with:

```text
java.lang.NoSuchMethodError:
  'void org.apache.spark.sql.catalyst.parser.ParserInterface.$init$(
    org.apache.spark.sql.catalyst.parser.ParserInterface)'
  at io.delta.sql.parser.DeltaSqlParser.<init>(DeltaSqlParser.scala:75)
  at io.delta.sql.AbstractDeltaSparkSessionExtension.$anonfun$apply$1(...)
```

This is a JVM binary-linkage failure during Delta session-extension
initialization. Consequently:

- Thrift health: **failed**;
- `dbt seed`: **not reached**;
- initial table model: **not reached**;
- incremental rerun: **not reached**;
- `dbt test`: **not reached**;
- `manifest.json` / `run_results.json`: **not produced**;
- Delta log / cross-client read: **not produced**.

Primary-source review identified the Spark-versioned artifact without changing
the selected Spark or Delta versions. The corrected proof uses
`io.delta:delta-spark_4.0_2.13:4.2.0`.
